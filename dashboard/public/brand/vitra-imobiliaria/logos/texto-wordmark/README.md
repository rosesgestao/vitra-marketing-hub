# Vitra Imobiliária — texto da logo (sem o símbolo)

Versões contendo **somente o texto** da logo horizontal aprovada (wordmark "VITRA" + descriptor
"IMOBILIÁRIA"), **sem o ícone "V" nem o separador**. Para crachás e materiais institucionais/endomarketing.

## Como foram feitas (fidelidade)
**Extração direta dos PNGs oficiais** aprovados (recorte do texto, à direita do separador, com remoção do
ícone). NÃO houve redesenho, substituição ou reinterpretação da tipografia — são os **próprios pixels
aprovados**. Logo, tipografia, desenho das letras, proporções, espaçamento e cores são idênticos ao oficial.

- Fonte oficial: `assets/brand/logos-brandbook-vitra-imobiliaria/horizontal-aprovada-hd/variacoes-cor/`
  (`vitra-mae-horizontal-aprovada-{branco,dourado,navy}-8k.png`).
- Fundo transparente · alta resolução (3609×962) · margem mínima consistente (66 px).

## Variações de cor (as 3 aplicações sobre fundo transparente)
- **branco**  — wordmark branco + descriptor branco (para fundos escuros).
- **dourado** — wordmark dourado + descriptor dourado.
- **navy**    — wordmark navy + descriptor dourado (para fundos claros).

> Obs.: existe uma 4ª aplicação no brandbook, **"escuro"** (wordmark branco + descriptor dourado sobre
> **bloco navy**). Por ser uma aplicação com fundo navy (não transparente), não entra nesta entrega de
> texto-transparente — posso gerá-la à parte se necessário.

## Sobre o SVG
Os `.svg` aqui **embutem o PNG** (mesmos pixels — 100% fiéis). Um SVG **vetorial** fiel não é possível sem
violar a regra "não redesenhar/interpretar a tipografia": o vetor oficial da logo usa um espaçamento
diferente do PNG de referência, e vetorizar (traçar) o PNG reinterpretaria os glifos. Se quiser um vetor,
o caminho correto é o arquivo vetorial oficial da marca (com a fonte Inter), ciente de que ele difere
levemente do PNG no espaçamento.
